# Learning Management System (LMS)

A lightweight Flask-based learning management system demo with course listings, course detail pages, and a learner dashboard.

## Features
- Course catalog with categories and enrollment counts
- Course detail pages with modules and assignments
- Learner dashboard with progress indicators
- Simple login page (mock)

## Getting started

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Then visit http://localhost:5000

## Project structure
- `app.py` - Flask app and mock data
- `templates/` - HTML templates
- `static/styles.css` - Shared styling
